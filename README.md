# Muse PVP Promotional Site

This is a standalone promotional HTML page, intentionally separate from the game client. `index.html` is self-contained: its favicon and all three promo images are embedded inside the HTML, so opening the file by itself will still show the artwork.

The page includes animated neon, scanline, shimmer, floating-image, hover, and card entrance effects. The `assets/` folder is also included for reference and reuse.
